# Spikes techniques

Question à trancher : **est-ce faisable avec 0 € et du temps bénévole ?**

Un spike est un petit essai jetable. On garde la **conclusion**, pas le code.

## Format d'une conclusion

```
### Spike N – <sujet>
- Date / versions testées :
- Question :
- Résultat : ✅ marche / ⚠️ marche avec limites / ❌ ne marche pas
- Limites constatées (chiffres) :
- Conséquence sur l'architecture :
- Temps passé :
```
