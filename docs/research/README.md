## Contexte de départ

- Terrain d'essai du MVP : le club de ski de l'auteur.
- Ambition : si ça marche, généraliser à d'autres associations.
- Contraintes : open source, budget 0 €, développé bénévolement (voir `../00-vision.md`).

## Règles

- Un spike = code jetable, **la conclusion est gardée** (date, version testée, limites, impact sur l'architecture).
- Toute affirmation sur un concurrent porte une source et une date de vérification.
